노드 이벤트 테스트

이벤트를 Redis Stream에 발행하고 Spring 워커의 처리 상태를 확인합니다.

현재 정상 이벤트는 Pending에 보류됩니다. 잘못된 JSON·미지원 버전은 DLQ로 이동합니다. 발행 성공은 노드 저장 완료를 뜻하지 않습니다. 조회 버튼으로 처리 결과를 확인하세요.

1. 이벤트 발행

샘플 버튼은 내용을 채우기만 합니다. 발행 버튼을 누르면 입력 문자열을 그대로 보냅니다. 같은 내용을 다시 발행하면 eventId도 동일합니다.

2. 상태 조회 및 응답

Pending은 최대 50건, DLQ는 최근 50건을 표시합니다. 조회는 메시지를 ACK하거나 삭제하지 않습니다.

요청을 선택하세요.
아직 응답이 없습니다.
