수치의 근거

  • 사용 시간은 회의 기록(봇 생성 요청 ~ 종료)으로 계산한다. Recall은 봇이 회의 URL을 여는 시점부터 과금하므로 실제 청구와 조금 차이가 난다.
  • fatal로 끝난 회의는 Recall이 과금하지 않으므로 제외한다. 대기실 시간은 포함된다.
  • ElevenLabs 전사는 Recall 봇이 우리 키로 호출하며, 과금 시간은 녹음 시간과 같다고 보고 같은 사용 시간에 단가를 곱한다.
  • 단가는 이 파일 아래 RATES 값이다. 공급자가 가격을 바꾸면 이 값만 고치면 된다.
